# Konaet µNEX-3F Public Demo

Este repositório contém o notebook público que baixa uma revisão imutável do
modelo `7dsolv/Konaet-Cauryvo-202M-muNEX-3F`, verifica a assinatura, os hashes e o contrato de
3 bits, carrega `model.mn3f` e gera respostas na tela.

[Abrir no Google Colab](https://colab.research.google.com/github/7dsolv/Konaet-muNEX-3F-Demo/blob/main/Konaet_muNEX3F_Demo.ipynb)

Modelo verificado: `b4399cf76835a77bfde0c72dfca6a6048d00f188`.

O notebook não chama uma API de texto e não baixa pesos de outro modelo. Ele
usa PyTorch e NumPy como infraestrutura de execução.
